# Pembaruan Paket 2026-11-05

---

Pembaruan paket terbaru kini tersedia untuk BlankOn Linux 26.09 Sinambung. Pembaruan kali ini mencakup 3 paket.

Perbarui sistem Anda melalui terminal:

```bash
sudo apt update && sudo apt full-upgrade
```

Atau perbarui melalui GNOME Software.

## Isi pembaruan ini

Pembaruan ini membawa versi baru dari paket-paket berikut, yang seluruhnya merupakan perbaikan untuk kerentanan keamanan tingkat tinggi pada APT, pengelola paket sistem:

| Paket         | Versi |
| ------------- | ----- |
| apt           | 3.3.6 |
| apt-utils     | 3.3.6 |
| libapt-pkg7.0 | 3.3.6 |

Kami sangat menyarankan Anda memasang pembaruan ini sesegera mungkin.

## Catatan keamanan

- **apt: pemasangan paket yang tidak terverifikasi (CVE-2026-109518).** Max Justicz menemukan bahwa APT dapat memasang paket yang telah ditukar setelah paket tersebut diverifikasi. Penyerang yang mampu memanipulasi lalu lintas HTTP antara komputer Anda dan mirror paket, misalnya mirror atau proxy yang berbahaya, dapat memanfaatkan celah ini untuk menjalankan kode sebagai root saat Anda memasang atau memperbarui paket. Celah ini terletak pada cara APT menangani unduhan yang dialihkan (redirect) atau dilanjutkan, dan berdampak pada konfigurasi bawaan karena APT secara bawaan mengulang unduhan yang gagal ([DSA-6607-1](https://www.debian.org/security/dsa-6607-1), [Debian security tracker](https://security-tracker.debian.org/tracker/CVE-2026-109518)). APT 3.3.6 memperbaiki celah ini sekaligus beberapa masalah akses di luar batas memori (out-of-bounds).

Kami memantau kerentanan keamanan yang dilaporkan di hulu (upstream) melalui [security.blankonlinux.id](https://security.blankonlinux.id/), dan melacak keadaan setiap paket di repositori kami melalui [packages.blankonlinux.id](https://packages.blankonlinux.id/).
