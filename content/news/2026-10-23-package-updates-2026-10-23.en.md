# Package Updates 2026-10-23

---

A new round of package updates is now available for BlankOn Linux 26.09 Sinambung. This round updates 7 packages.

Update your system from the terminal:

```bash
sudo apt update && sudo apt full-upgrade
```

Or update via GNOME Software.

## What's in this update

This update brings new versions of the following packages, all of which are fixes for critical security vulnerabilities disclosed this week:

| libapache2-mod-php8.4 | 8.4.27-1      |

We strongly recommend installing this update as soon as possible.

## Security notes

- **ca-certificates: eMudhra / emSign certificate incident.** The private keys of eight intermediate certificate authorities operated by eMudhra were compromised, and browsers and operating systems are removing trust in the affected certificates ([The Hacker News](https://thehackernews.com/2026/10/eight-emudhra-ca-keys-compromised.html), [eMudhra's statement](https://emudhra.com/en/post/certificate-security-incident)). This update stops trusting the "emSign ECC Root CA - G3" and "Comodo AAA Services root" certificates, so certificates issued through the compromised intermediates are no longer accepted by applications that use the system certificate store.
- **php8.4: PHP2Shell (CVE-2026-109618 and CVE-2026-109619).** Two critical flaws in PHP may let an unauthenticated attacker run code on a web server that uses PHP. Details leaked ahead of the planned disclosure, and exploitation attempts have been reported ([Help Net Security](https://www.helpnetsecurity.com/2026/10/21/php2shell-php-vulnerabilities-patched-cve-2026-109618-cve-2026-109619/), [watchTowr](https://watchtowr.com/intelligence/php-remote-code-execution-php2shell/)). PHP 8.4.27 fixes both. Workarounds circulating online do not fully protect you ([Datadog Security Labs](https://securitylabs.datadoghq.com/articles/php2shell-critical-vulnerabilities-in-php/)), so updating is the only complete fix.

## We want your feedback

We monitor security vulnerabilities reported upstream through [security.blankonlinux.id](https://security.blankonlinux.id/), and track the state of every package in our repositories through [packages.blankonlinux.id](https://packages.blankonlinux.id/).
