# Package Updates 2026-10-20

---

A new round of package updates is now available for BlankOn Linux 26.09 Sinambung. This round updates 72 packages.

> **Known issue with Praya:** the Praya panel may glitch if it is updated while it is running. To avoid this:
>
> 1. Disable Praya in the GNOME Extensions app.
> 2. Update your system as shown below.
> 3. Log out and log back in.
> 4. Enable Praya again in the GNOME Extensions app.
>
> We are working on a fix for the next update.

Update your system from the terminal:

```bash
sudo apt update && sudo apt full-upgrade
```

Or update via GNOME Software.

## What's new in Praya

Praya, BlankOn's GNOME Shell extension, has been updated to 0.1.45. Notable changes:

- **Configurable application tray column size.** You can now set how many columns the application tray uses ([#50](https://github.com/BlankOn/praya-gnome-shell-extension/pull/50)).

  ![Praya application menu in a four-column grid, next to the Praya settings with the grid column option set to 4 columns](/content/assets/praya-update-four-column-grid-panel.png)

- **Editable start icon button.** The start button icon can be replaced, so anyone can rebrand Praya and use it in their own distribution ([#53](https://github.com/BlankOn/praya-gnome-shell-extension/pull/53)).

  ![Praya settings showing the start button options, with the icon and label changed to a custom text](/content/assets/praya-update-customizable-start-button.png)

- **Improved search.** You can now search for files directly from the Praya panel ([#56](https://github.com/BlankOn/praya-gnome-shell-extension/pull/56)).

  ![Praya panel search showing matching files and folders from the home directory](/content/assets/praya-update-search-files.png)

- **Minor fixes.** See the [full list of recent merged pull requests](https://github.com/BlankOn/praya-gnome-shell-extension/pulls?q=is%3Apr+is%3Amerged).

## We want your feedback

We monitor security vulnerabilities reported upstream through [security.blankonlinux.id](https://security.blankonlinux.id/), and track the state of every package in our repositories through [packages.blankonlinux.id](https://packages.blankonlinux.id/). Both are open to everyone, so you can see for yourself what is affected and which version fixes it.

If you run into a problem after updating, or have suggestions, please tell us in our [Telegram group](https://t.me/BlankOnLinux). Your reports from real machines are the most valuable testing we can get.
