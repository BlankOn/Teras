# Package Updates 2026-11-05

---

A new round of package updates is now available for BlankOn Linux 26.09 Sinambung. This round updates 3 packages.

Update your system from the terminal:

```bash
sudo apt update && sudo apt full-upgrade
```

Or update via GNOME Software.

## What's in this update

This update brings new versions of the following packages, all of which fix a high-severity security vulnerability in APT, the package manager:

| Package       | Version |
| ------------- | ------- |
| apt           | 3.3.6   |
| apt-utils     | 3.3.6   |
| libapt-pkg7.0 | 3.3.6   |

We strongly recommend installing this update as soon as possible.

## Security notes

- **apt: unverified package installation (CVE-2026-109518).** Max Justicz discovered that APT could install a package that was swapped out after it had been verified. An attacker who can tamper with HTTP traffic between your computer and a package mirror, such as a malicious mirror or proxy, could use this to run code as root when you install or upgrade packages. The flaw lies in how APT handles downloads that are redirected or resumed, and it affects default configurations because APT retries failed downloads by default ([DSA-6607-1](https://www.debian.org/security/dsa-6607-1), [Debian security tracker](https://security-tracker.debian.org/tracker/CVE-2026-109518)). APT 3.3.6 fixes this issue along with several out-of-bounds access issues.
